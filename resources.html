Resources

Where to read more, and run the real thing

A short list. Links were not checked from the build environment; if one is dead, tell us.

The list

  • TempleOS on Wikipedia

    A sourced overview of the system, its history and its reception. Start here to check anything on this site.

  • Terry A. Davis on Wikipedia

    A sourced biography, written with more care than a page like ours can offer.

  • holyc-lang: a HolyC compiler

    A community compiler for HolyC, written in C, with a JIT, a REPL and an assembler. Its README describes it as working but with rough edges. BSD-style licence.

  • holyc-lang documentation

    The documentation for that compiler, listed in its README.

  • templeos.org

    Davis's original site for the system. Not checked from here; it may be an archive or unavailable.

To run real HolyC, use a community compiler such as holyc-lang or run TempleOS itself in a virtual machine. This site's playground is a teaching tool, not a substitute.
